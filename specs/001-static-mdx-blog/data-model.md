# Data Model: Static MDX Blog

**Branch**: `001-static-mdx-blog` | **Date**: 2025-12-18

This document defines the data structures and relationships for the static MDX blog feature.

## Entities

### Post

The primary content entity representing a blog article.

```typescript
interface Post {
  // Required frontmatter (author-provided)
  title: string;           // Post title (FR-001)
  date: string;            // ISO 8601 date (FR-001)
  author: string;          // Author name for byline (FR-015)

  // Optional frontmatter (author-provided)
  slug?: string;           // URL slug, defaults to folder name (FR-002)
  tags?: string[];         // Array of tag strings (FR-004)
  excerpt?: string;        // Short description, auto-generated if omitted (FR-003)

  // Computed at build time
  readingTime: number;     // Minutes to read (FR-012)
  wordCount: number;       // Total word count
  toc: TOCEntry[];         // Table of contents structure (FR-006)
  content: string;         // Compiled MDX/HTML content
}
```

**Validation Rules**:
- `title`: Non-empty string, max 200 characters
- `date`: Valid ISO 8601 date string (YYYY-MM-DD)
- `author`: Non-empty string
- `slug`: Lowercase alphanumeric with hyphens, no spaces
- `tags`: Each tag lowercase alphanumeric with hyphens

**Source**: `blog/[slug]/index.mdx` frontmatter + content

### TOCEntry

Represents a heading in the table of contents hierarchy.

```typescript
interface TOCEntry {
  id: string;              // Anchor ID (generated by rehype-slug)
  text: string;            // Heading text content
  level: 2 | 3;            // h2 or h3 (h1 reserved for title)
  children?: TOCEntry[];   // Nested h3s under h2
}
```

**Source**: Extracted by rehype-extract-toc during MDX compilation

### Tag

Aggregated tag metadata for the blog index.

```typescript
interface Tag {
  name: string;            // Display name (original case from first usage)
  slug: string;            // URL-safe identifier (lowercase)
  count: number;           // Number of posts with this tag
}
```

**Derivation**: Computed from all posts at build time

### SearchIndexEntry

Entry in the Fuse.js search index.

```typescript
interface SearchIndexEntry {
  slug: string;            // Post URL slug
  title: string;           // Post title (weighted high)
  excerpt: string;         // Post excerpt (weighted medium)
  tags: string[];          // Post tags (weighted medium)
  content: string;         // Plain text content (weighted low)
}
```

**Source**: Generated by prerender script from all posts

### PostCard

Lightweight post metadata for listing pages.

```typescript
interface PostCard {
  slug: string;
  title: string;
  date: string;
  author: string;
  excerpt: string;
  tags: string[];
  readingTime: number;
}
```

**Usage**: Blog index page, search results, related posts

## Frontmatter Schema

MDX files use YAML frontmatter with this schema:

```yaml
---
title: "Getting Started with TerraConstructs"  # Required
date: 2025-01-15                                # Required (ISO date)
author: "Jane Developer"                        # Required
slug: getting-started                           # Optional (defaults to folder name)
tags:                                           # Optional
  - aws
  - tutorial
  - beginner
excerpt: "Learn how to set up your first..."   # Optional (auto-generated)
---
```

## State Transitions

Posts have no runtime state changes (static content). Client-side state:

| State | Scope | Description |
|-------|-------|-------------|
| `activeTag` | Blog index | Currently filtered tag (from URL hash) |
| `searchQuery` | Blog index | Current search input |
| `activeSection` | Post page | Currently visible TOC section |
| `tocExpanded` | Post page (mobile) | TOC drawer open/closed |

## Relationships

```
Post 1──* Tag           # A post has many tags
Tag  1──* Post          # A tag groups many posts (derived)
Post 1──* TOCEntry      # A post has many TOC entries
Post 1──1 SearchIndexEntry  # One-to-one for search
```

## Validation at Build Time

The prerender script MUST fail the build with clear errors if:

1. **Missing required frontmatter**: `title`, `date`, or `author` absent
2. **Invalid date format**: Not ISO 8601 compliant
3. **Duplicate slugs**: Two posts resolve to same URL
4. **Invalid tag format**: Contains spaces or special characters
5. **Broken internal links**: MDX links to non-existent posts

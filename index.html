Everything you need to know about TerraConstructs

TerraConstructs is a library of Level 2 CDKTF Constructs that are ported from AWS CDK L2 constructs. The key difference is that TerraConstructs synthesizes to pure Terraform/OpenTofu configurations instead of CloudFormation, eliminating vendor lock-in while maintaining the developer experience of AWS CDK.

Yes! TerraConstructs generates standard Terraform HCL configurations that can be integrated with existing Terraform code. You can gradually migrate to TerraConstructs or use it alongside your current infrastructure code.

Extremely reliable. All AWS CDK unit tests have been ported to ensure feature parity, and we maintain extensive end-to-end tests that validate the generated Terraform configurations work in real AWS environments. The codebase is fully deterministic.

Yes! Since TerraConstructs generates standard Terraform HCL, it works seamlessly with both Terraform and OpenTofu. This gives you flexibility in your infrastructure toolchain without any vendor dependencies.

TerraConstructs supports the most commonly used AWS services including VPC, EC2, S3, CloudFront, RDS, Lambda, and many more. We continuously add support for additional services based on community feedback and AWS CDK updates.

Absolutely. TerraConstructs is designed for production-scale deployments with platform teams in mind. It provides consistent patterns, comprehensive testing, and deterministic outputs that enterprises require for reliable infrastructure management.

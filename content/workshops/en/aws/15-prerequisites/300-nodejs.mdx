## Node.js

CDKTN runs on Node.js. We recommend the current Node.js 24 LTS release
(v24.22.3 at the time of writing).

* To install Node.js visit the [node.js](https://nodejs.org) website.

    * __Windows__: if you have an old version of Node.js installed on your
      system, it may be required to run the .msi installation as Administrator.

* If you already have Node.js installed, verify that you have a compatible version:

    ```
    node --version
    ```

    Output should be a 24.x release, for example:

    ```
    v24.22.3
    ```

## pnpm

This workshop uses [pnpm](https://pnpm.io) to manage the project's packages.
`cdktn init` with the pnpm template needs pnpm 10.26 or newer.

* Install pnpm with one of the methods in the
  [pnpm installation guide](https://pnpm.io/installation), for example with npm:

    ```
    npm install -g pnpm@latest
    ```

* Verify that pnpm is on your `PATH`:

    ```
    pnpm --version
    ```

    Output should be 10.26 or newer, for example:

    ```
    11.17.0
    ```
